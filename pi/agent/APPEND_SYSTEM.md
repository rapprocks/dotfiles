# Obsidian Shared Memory Workflow
- Before making architectural changes, use your read tool to check `~/valut/02-memory/decisions.md` and check `~/vault/03-docs/prompts/` for relevant patterns.
- When finishing a task, use your bash tool to append a 1-line summary (Task, Files Changed, Lessons Learned) to `~/vault/00-inbox/changelog.md`.
- If you make a significant technical decision, append your reasoning to `~/vault/02-memory/decisions.md` before ending the session.
